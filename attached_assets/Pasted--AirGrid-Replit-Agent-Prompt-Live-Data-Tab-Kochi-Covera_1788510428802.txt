## Notes

- The Live Data tab intentionally does **not** touch your existing IDW/hotspot/forecast pipeline — it's a separate, simpler "raw API passthrough" view. Keeping it separate avoids destabilizing the estimation logic you already have working.
- Open-Meteo needs no API key for either endpoint, so this tab will work immediately with zero config. OpenAQ live lookups will only activate if you've set `OPENAQ_API_KEY` — otherwise that specific card should just say "OpenAQ not configured" rather than erroring.
- If Agent asks for exact Kochi-area station coordinates, these are close enough for demo purposes: Kochi Central ~9.9816, 76.2999; Kalamassery ~10.0518, 76.3315; Edappally ~10.0261, 76.3086; Vyttila ~9.9678, 76.3184; Aluva ~10.1076, 76.3517; Tripunithura ~9.9447, 76.3489; Fort Kochi ~9.9646, 76.2424; Kakkanad ~10.0159, 76.3419.
